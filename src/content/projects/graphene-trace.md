## Overview

Graphene Trace is a comprehensive healthcare solution designed to prevent pressure ulcers through real-time pressure monitoring. The application provides medical staff with intuitive heatmap visualizations and analytics to identify at-risk patients.

## Key Features

- **Real-time Pressure Monitoring** - Live data visualization with interactive heatmaps
- **Clinical Workflow Integration** - Designed for seamless integration into healthcare environments
- **Analytics Dashboard** - Comprehensive data analysis with Plotly.js visualizations
- **Secure Authentication** - JWT-based authentication with bcrypt password hashing
- **Containerized Deployment** - Full Docker and docker-compose setup for easy deployment

## Tech Stack

- **Backend**: FastAPI, Python, SQLAlchemy
- **Frontend**: React, TypeScript, Vite, Plotly.js
- **Database**: PostgreSQL
- **DevOps**: Docker, docker-compose
- **Security**: JWT, bcrypt
