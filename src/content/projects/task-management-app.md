## Overview

A full-featured task management application designed for teams. Features real-time collaboration, project boards, and deadline tracking.

## Key Features

- **Kanban Boards** - Drag-and-drop task organization
- **Team Collaboration** - Share boards and assign tasks
- **Real-time Updates** - Changes sync instantly across all users
- **Notifications** - Get alerted about deadlines and mentions
- **Dark Mode** - Easy on the eyes for late-night work sessions

## Architecture

The application uses a serverless architecture with:

- Next.js for the frontend and API routes
- Firebase Firestore for real-time database
- Firebase Auth for authentication
- Vercel for hosting

## What I Learned

This project deepened my understanding of real-time applications and the challenges of handling concurrent updates from multiple users.
