## Overview

A responsive weather dashboard that provides real-time weather data with stunning visual representations. Uses the OpenWeatherMap API for accurate forecasting.

## Features

- **Current Conditions** - Temperature, humidity, wind speed, and more
- **7-Day Forecast** - Weekly outlook with high/low temperatures
- **Location Search** - Find weather for any city worldwide
- **Geolocation** - Automatic weather for your current location
- **Interactive Charts** - Beautiful data visualizations

## Technical Details

Built with React and styled using CSS custom properties for easy theming. The application uses:

- React Query for data fetching and caching
- Recharts for interactive weather graphs
- Framer Motion for smooth animations
- Local storage for saving favorite locations

## Challenges

The main challenge was handling the various edge cases in the API responses and ensuring a smooth user experience even with slow network connections.
